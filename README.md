## Getting Started
### Production
First,
```
bun run build
```

Then,
```
bun run start
```

### Development
#### Prerequisites
##### MacOS
##### Homebrew
##### Rust
##### .git
##### `tree`
#### Installation
```bash
bun install
```

#### Building
```bash
bun run dev
```

